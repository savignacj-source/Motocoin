# MotoCoin — Documents légaux

Pages légales publiques de l'application mobile MotoCoin.

## Contenu

- `index.html` — Page d'accueil avec liens
- `privacy.html` — Politique de confidentialité (RGPD)
- `terms.html` — Conditions générales d'utilisation

## Hébergement

Ces pages sont publiées via **GitHub Pages**.

URL publique : `https://<username>.github.io/motocoin-legal/`

## Configuration GitHub Pages

1. Aller dans **Settings** du repo
2. Section **Pages**
3. Source : `Deploy from a branch`
4. Branch : `main` / `/` (root)
5. Sauvegarder → URL publique générée en quelques minutes

## Avant publication

⚠️ Compléter dans `privacy.html` :
- Email de contact RGPD (section 1)

⚠️ Adapter dans `terms.html` si besoin (dénomination juridique si auto-entreprise créée).
